HOW TO UPLOAD (about three minutes)
  1. Open https://github.com/TheSeanMitchell/PartyPortal
  2. Add file > Upload files. Drag in the eight files: index.html, channels.json, bot.py, sw.js,
     CHANGELOG.md, README.md, events.json, health.json (not this note). They replace the old
     ones (3.2, which is the version live now). Commit message, for example: "v3.3".
     Commit changes.
  3. Run the refresh once: the upload of bot.py starts it by itself (Actions tab: "Daily Culture
     Feed Refresh"). If it does not appear within a minute: Actions > Daily Culture Feed
     Refresh > Run workflow > Run workflow.

CHECK (about five minutes later)
  - https://theseanmitchell.github.io/PartyPortal/ (reload once if the old page shows): On The
    Horizon has a LAS VEGAS button; the VEGAS ON-SALE RADAR is below the news.
  - https://theseanmitchell.github.io/PartyPortal/health.json shows "version": "3.3.0".

OPTIONAL - A FREE TICKETMASTER KEY (only you can make it; it fills the radar)
  1. Sign up free at https://developer.ticketmaster.com and copy your app's "Consumer Key".
  2. In the GitHub repo: Settings > Secrets and variables > Actions > New repository secret.
     Name: TICKETMASTER_API_KEY   Secret: paste the key. Add secret.
  3. Actions > Daily Culture Feed Refresh > Run workflow.
  What it adds: the radar gets Ticketmaster's official public on-sale and presale dates and
  times for the Las Vegas area (up to 100 events each refresh); the calendar gets up to 12
  Ticketmaster events in each of 18 cities, Las Vegas included, for the next 45 days.
  health.json then shows "ticketmaster_key": true.
